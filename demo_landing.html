Key Features

Metadata Threat Detection

Detect code injection, SQL injection, command injection, Base64 payloads, and obfuscated content hidden in file metadata.

YARA Rule Integration

Apply custom and built-in YARA rules for pattern-based malware detection, steganography, and enterprise threat matching.

ML Ensemble Detection

Multi-model anomaly detection combining Isolation Forest, Random Forest, and XGBoost with weighted voting across 25 features.

MITRE ATT&CK Mapping

Automatically maps findings to MITRE ATT&CK techniques and tactics for standardized threat intelligence reporting.

Deep Format Analysis

Native parsing for PDF JavaScript, Office macros, OLE, DDE, template injection, polyglot files, and SVG threats.

Enterprise Ready

REST API, WebSocket live updates, RBAC, evidence chain with chain-of-custody, SIEM integration, and plugin marketplace.
